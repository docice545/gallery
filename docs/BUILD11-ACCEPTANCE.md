# Gallery Build 11: приёмка и границы подтверждённых результатов

Application source: `f26b46059726ca3c55c63c3ce1edde7e45d8404f`.
Версия: **5.7.3 (11)**. Ветка: `candidate/gallery-5.7.3-build11-upstream`.
Production HP, реальные семейные оригиналы и физические телефоны не участвовали
в автоматических испытаниях. Все destructive-тесты использовали disposable DB,
пользователей и синтетические файлы.

`PASS` в колонке «Автоматически» относится только к указанной среде и границам
теста. Он не переносится на Synology NFS, установленный Android/iOS или production
данные. `NOT TESTED` требует фактической приёмки; результат нельзя заменять
просмотром исходников. Ошибка original-file safety, ownership, restore или rollback
означает `FAIL` и блокирует соответствующий этап выпуска.

разными capture dates и приватным тестовым альбомом. Не выбирать семейные

## Обязательные ограничения готовности

1. Даже successful synthetic installation lab не означает production deployment
   или physical device PASS. Реальные HP/NFS/телефоны остаются operator gates.
2. Установочный релиз нельзя объявить READY без published immutable package,
   checksum verification и actual clean-install/upgrade/rollback report.
3. Доказанная база совместимости — Noodle `v5.7.1`; latest official `v5.8.0`
   требует отдельной schema/protocol/build integration. Приёмка не утверждает
   полной совместимости с непроверенным upstream version.
4. Downgrade к stock Noodle с durable deletion tables не поддерживается. Rollback
   использует проверенный schema-compatible hardened image и сохраняет receipts;
   destructive down migration не выполняется. Уже окончательно удалённые файлы
   не возвращаются image rollback: для этого нужны проверенные media backups.
5. Возобновление production paused queue/retention, signing и deployment — отдельные
   approvals. Установка не является разрешением активировать legacy FileDelete
   или выполнять необратимую операцию с реальными originals.
