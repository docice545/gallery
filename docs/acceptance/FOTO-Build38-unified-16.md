## Команды облачного воспроизведения

Использовать существующий setup, Flutter **3.47.2**, Dart **3.13.2**, JDK **21**, Android SDK **36**, frozen dependencies. `flutter` должен быть в PATH также для дочерних процессов. Codegen — существующий `mobile/scripts/android_media_codegen.sh`; для iOS — `ios_build_only.sh`. Никакого массового обновления зависимостей.

```bash
# Корень checkout; после существующего setup/codegen.
(cd mobile && flutter analyze --no-pub)
(cd mobile && flutter test --no-pub --concurrency=2 --reporter expanded)
(cd mobile/android && bash gradlew :app:testDebugUnitTest --console=plain)
pnpm --dir server test run
python3 -m unittest discover -s scripts/release/tests -v
python3 -m unittest discover -s mobile/scripts/tests -v
python3 docs/acceptance/test_hp_handoff.py -v
```

Все тестовые пути в следующей таблице относительно `mobile/`, кроме явно указанных server/Python. Точная команда для строки: **`cd mobile && flutter test --no-pub <указанные пути> --reporter expanded`**. Эти тесты фактически исполнены полной suite; исторические focused receipts приведены по ссылкам. Повторный запуск может включать новые тесты, поэтому количество в старом focused receipt не обещается для другого SHA.
