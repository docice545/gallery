## 1. Панели выделения

Причина различий: `CompactSelectionToolbar` имел отдельную строку фиксированной высоты 76 dp, а контекстные `BaseBottomSheet` сразу открывали `DraggableScrollableSheet` высотой 18–40% экрана, с ручкой, разделителем и содержимым ниже видимой области. Поэтому три действия занимали значительно больше места в локальной библиотеке и альбомах.

Оба пути используют `SelectionToolbarFrame`, существующий `ViewerControlSurface` и `ActionCellGrid(compact: true)`: одинаковая поверхность, скругления 28 dp, боковой отступ минимум 12 dp, системные safe-area отступы, высота по содержимому. Иконки имеют область нажатия 48 dp. При крупном шрифте действия переходят в две строки; подписи не обрезаются и не разрываются внутри слов. Верхний счётчик имеет видимую капсулу 32 dp и область нажатия 48 dp. Используются текущие темы и основной цвет приложения, существующие иконки FOTO.

## 2. Лента

Причина пустоты подтверждена воспроизводящим тестом: жадный подбор высоты завершал горизонтальную строку до последнего портретного видео. Конечная неполная строка сохраняла большую высоту, но занимала только небольшую часть ширины. Загрузка картинки и выделение не были причиной этой конкретной пустоты.

`FixedRowLayout.justified` теперь проверяет ограниченное конечное окно внутри одного временного сегмента и выбирает заполненные строки с сохранением порядка. Для двух кадров 16:9 и видео 9:16 / 00:39 последний кадр и видео делят строку. Пропорции видео сохраняются; в плотных режимах допускается ограниченное cover-кадрирование соседнего горизонтального кадра (до 20%). Нельзя переносить элементы через дату/месяц.

Если заполнение невозможно — например, в дате есть только один портрет — карточка центрируется, высота ограничена 128 dp при штатных настройках, минимальная ширина 72 dp сохраняет возможность выбора. Это явное исключение, а не обещание заполнить всю ширину любой ценой. Одиночные горизонтальные фотографии и панорамы сохраняют ограниченную полноширинную компоновку. Геометрия placeholder и готовой миниатюры совпадает. Полная длительность видео масштабируется по доступной ширине без переполнения.

Проверки в `justified_timeline_widget_test.dart` выполняют настоящий sliver-рендер с `ThumbnailTile`, декодированием синтетических пикселей через native-image контракт и реальной надписью **00:39**. Это не только поиск пустых виджетов. Проверяются заполнение строк, пропорции видео, пиксели готовых миниатюр, неизменность прямоугольников и ID при выделении. Сценарий запущен в 16 сочетаниях: classic/immersive × плотность 2/3/4/5 × светлая/тёмная тема. Существующий тест `real sliver mosaic renders ... without empty cells` усилен сравнением с декодированным цветом источника.

Дополнительно: задержанная загрузка миниатюр без скачков, одиночный портрет на границе месяца, панорамы и смешанные пропорции, 320×568 / 390×844 / 844×390 с шрифтом 160%, сохранение Live Photo/stack/storage индикаторов. Библиотека 50 000 смешанных фото/видео прокручивается в середину: видимые элементы реально загружены, индекс больше 20 000, построено меньше 50 плиток, каждая загрузка каталога ограничена 1024 элементами, запросов изображений меньше 100. Это проверка виртуализации, не измерение FPS Samsung.
